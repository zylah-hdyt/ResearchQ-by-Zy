# Limit Claude: 5 visual directions

Five 15 s vertical videos (1080×1920, 30 fps) over the same voice-over. Storyboards: [STORYBOARDS.md](STORYBOARDS.md).

| ID | Style | Source |
|---|---|---|
| `V1-Cinematic3D` | Cinematic 3D (Three.js, glass + light) | `src/v1-cinematic3d/` |
| `V2-KineticType` | Kinetic typography | `src/v2-kinetic/` |
| `V3-Documentary` | Cinematic documentary (Unsplash photos) | `src/v3-documentary/` |
| `V4-TechUI` | Futuristic tech interface (Three.js particles + HUD) | `src/v4-techui/` |
| `V5-PaperCraft` | 3D paper & mixed media (stop-motion 15 fps) | `src/v5-paper/` |

## Voice-over

`public/vo.wav` is the recut of `scripts/source_vo.m4a` (46.7 s → 15.000 s): sentences 1–5, pauses tightened, tempo 1.2x with pitch preserved. Rebuild with:

```bash
python3 scripts/recut_vo.py scripts/source_vo.m4a public/vo.wav
```

Word timings (`scripts/words_raw.json`) drive every beat; the constants live in `src/shared/timing.ts`.

## Assets

- Photos and paper texture: Unsplash URLs embedded in the code (no local images).
- Fonts: Google Fonts via `@remotion/google-fonts`.
- SFX: `https://remotion.media/*.wav` plus procedural beds/hits in `public/sfx/` generated by `scripts/make_sfx.sh`.

## Commands

```bash
npm install
npm run studio          # preview
npm run render:all      # all five → out/*.mp4
scripts/stills.sh V3-Documentary v3 20 140 300   # contact sheet of chosen frames
```

Rendering in this cloud environment uses `scripts/chrome-proxy.sh` (pre-installed Chromium routed through the HTTPS proxy, SwiftShader GL). On a normal machine you can delete the `setBrowserExecutable`/`setChromeMode` lines in `remotion.config.ts` and use `--gl=angle`.
