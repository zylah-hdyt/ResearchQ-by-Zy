# ResearchQ / NotYourLecture: instruksi untuk Claude

Repo ini berisi video motion graphic yang dibuat dengan kode (HTML `render(t)` + Playwright + ffmpeg), maskot talking head dengan lip-sync, VO, SFX, dan thumbnail.

**Sebelum membuat video/animasi/thumbnail apa pun:**
1. Ekstrak `output/ResearchQ_Studio_Pack.zip` ke folder kerja (mis. `unzip output/ResearchQ_Studio_Pack.zip -d $WORK`).
2. Baca `ResearchQ_Studio_Pack/START_HERE.md`, lalu semua file di `docs/` (terutama `01_STYLE_GUIDE.md`, `06_RULES_AND_LESSONS.md`, `07_HISTORY_VIDEO_ENGINE.md`, `08_REFERENCE_SHORTS_EXPLAINER.md`).
3. Ikuti aturan QA di docs/06: kirim sampel (suara, satu adegan, SFX) dulu dan minta persetujuan sebelum render penuh; cek gerak, bukan hanya frame diam; jangan klaim audio beres bila belum didengar.
4. Jangan membuat/mengubah maskot; logo hanya dari file yang diberikan user; bahasa Indonesia harus natural, bukan terjemahan.
5. Video-video contoh (resolusi penuh) ada di `output/`; sumber tiap video di `output/source_*` dan `output/youtube_*`.
